# 0.2.2 자동 준비 / 10% 페달 여백

- 사용자 승인: 시작 시 자동 중앙/자동 운전, 조향 90°=50%·180°=100% 유지, 페달 위아래 10%를 100%/0% 구간으로 사용. 기존 95% 스냅과 전체 높이 1:1은 새 요청으로 대체.
- 코드: `AutoDrive` 순수 상태 머신. 500ms/2° 안정 자세에서 1회 보정, 터치 없음+중립+신선한 센서/연결 700ms 뒤 ARM. 운전 중에는 보정 안 함. 해제는 재개 전까지 유지. PC의 기존 300ms 중립/150ms watchdog/HMAC 조건 유지. 앱/옵션 포커스 상실 시 해제. 거부된 ARM은 낮춘 뒤 다시 중립 대기. 활성 주행 중 UI 지연만으로 센서/통신 worker를 불필요하게 중단하지 않음.
- 실제 폰 View bounds `[0,0][2316,904]` 확인: 코드상 위아래 10% 터치 제한은 없었음. 새 물리 여유 구간은 사용자 선택으로 도입. 흰 선/원에 실제 Android 접촉 중심 표시, 화면상 터치 %와 출력 % 구분. 바/글자 겹침을 확인하고 터치 설명은 하단으로 이동.
- Android 빌드/단위 시험 및 lint 통과. AutoDrive 7 + Core 13 + Pairing 3 + Transport 3 = 26 tests. C# 11/11 groups 통과. 기존 lint/ZXing deprecation 경고 존재.
- PC EXE 게시 성공. USB TCP 회귀: malformed length/fragmented Hello/authentication/동시 트리거/부분 프레임 watchdog PASS, 마지막 완전 Control→해제 152.430ms (loopback, 케이블 지연 실측 아님).
