# Android 0.5.8 — single gamepad UI

Requested removal: Race mode, Race shortcut option, bottom mode switch and
standalone PTT target/drawing are removed. Existing ABXY/D-pad/LB/RB/Back/Start,
pedal dimensions/settings and right stick remain. No new gamepad mapping.
The LB bit is still forwarded unchanged. Its press/release edges additionally
operate Wendy only when enabled in manual PTT mode; OFF/AUTO ignores these
manual voice edges. No settings dialog or microphone opens from LB when OFF.

The sender, calibration, ARM/recovery, PC Receiver and gamepad output code were
not changed by 0.5.8. Receiver remains 0.5.7 and was not restarted for this edit.

Build: offline testDebugUnitTest / assembleDebug / assembleDebugAndroidTest /
lintDebug PASS. Android unit tests: 48, failures/errors: 0. Existing scanner
deprecation and hardcoded-English lint warnings remain.

New LB edge tests cover combined buttons, repeated samples, release/cancel and
next press. The isolation test now verifies that tapping the former bottom
switch cannot generate buttons or interrupt a held pedal. A detached device UI
test covers both held pedals, all 12 existing buttons, unchanged LB mapping,
PTT edges, right stick, and inert former PTT/switch positions, without creating
a controller connection or opening a microphone.

Initial installation was blocked by a disconnected ADB device. After the user
reconnected Fold5, both APK and test APK installed successfully. Installed
version confirmed: 0.5.8, versionCode 20. App opened after the test.

Actual Fold5 detached UI test: PASS (instrumentation code 0).
All 12 original gamepad buttons retained their bit values while both pedals
remained held at 50%. LB produced one PTT press/release pair. Right-stick motion
and release passed; the former center PTT and bottom switch locations were inert.
Cancel released all held controls. No microphone, controller connection or game
output was created by this test. PC Receiver was not restarted.
